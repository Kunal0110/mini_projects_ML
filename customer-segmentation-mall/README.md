# Mall Customer Segmentation

Mini-project: segment mall customers using clustering on the Mall Customers dataset and derive actionable marketing insights.

## Project Structure

- `data/raw/Mall_Customers.csv` – original dataset from Kaggle
- `notebooks/customer_segmentation.ipynb` – EDA, choosing k, visualizations
- `src/cluster_customers.py` – reproducible clustering script and report generator
- `reports/customer_segmentation.md` – final written report
